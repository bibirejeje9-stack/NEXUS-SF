# NEXUS SF Performance Club

Premium, cinematic fitness website for a San Francisco performance club.

## Brand
**BUILD STRENGTH. ELEVATE LIFE.**

## Stack
Next.js, React, TypeScript, Tailwind CSS, GSAP/ScrollTrigger.

The project follows the approved NEXUS SF master brief: luxury × athletic × futuristic, with consultation booking, equipment, memberships, programs, trainers, weight loss, location and contact experiences.
